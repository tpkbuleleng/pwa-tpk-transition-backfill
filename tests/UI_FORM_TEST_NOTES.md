# UI Form Test Notes — Paket 4

Checklist uji manual:

1. Buka GitHub Pages.
2. Pastikan mode BACKFILL tampil.
3. Klik Cek Backend, pastikan healthCheck tetap success.
4. Klik Isi Contoh Valid pada Form Registrasi Sasaran Awal.
5. Pastikan status validasi sasaran berhasil.
6. Klik Simpan Draft, lalu Muat Draft, lalu Hapus Draft.
7. Klik Isi Contoh Valid pada Form Pendampingan Backfill.
8. Pastikan status validasi pendampingan berhasil.
9. Ubah periode bulan menjadi Juli atau tanggal tidak sesuai bulan, pastikan validasi gagal.
10. Pastikan tidak ada data yang terkirim ke Google Sheet pada Paket 4.
